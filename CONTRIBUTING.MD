# Contributing to Silicon Dreams

Thanks for your interest! I'm currently taking a break from active development, but feel free to fork and submit PRs.

## How to Run Locally
1. Clone the repo.
2. Run `npm install`.
3. Create a Firebase project and add keys to `.env`.
4. Run `npm run dev`.

## Project Structure
- `/src/store` - Zustand state management (Game Logic)
- `/src/components` - React UI components
- `/src/utils` - Helper functions for sound and math

## Code Style
Please run the linter before submitting:
npm run lint
